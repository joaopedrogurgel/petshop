Software para Gerenciamento de Petshop - Parte 02
Programação de Sistemas Web - UEM

Link do sistema hospedado:
https://petshop-ashy-eight.vercel.app

Ambiente(s) de desenvolvimento:
macOS. O banco de dados foi criado no Supabase e os testes foram feitos
diretamente no sistema publicado na Vercel.

Servidor web:
Vercel, com o runtime da comunidade vercel-php (versão 0.9.0, PHP 8.5),
configurado no arquivo vercel.json.

Sistema gerenciador de banco de dados:
PostgreSQL, hospedado no Supabase. Acesso pelo PHP com PDO (driver pgsql).

Framework(s):
Bootstrap 5.3.3 (carregado via CDN).

Biblioteca(s):
Nenhuma além do Bootstrap.

Instruções de instalação:
1. Criar um banco PostgreSQL (no projeto foi usado o Supabase).
2. Importar o repositório do GitHub na Vercel.
3. Cadastrar na Vercel as variáveis de ambiente listadas abaixo.
4. Criar as tabelas cliente, funcionario, animal e atendimento executando,
   no SQL Editor do Supabase, os comandos create table do arquivo
   api/criar_tabelas.php.

Instruções de execução:
Acessar o link do sistema hospedado em um navegador. Não é necessário
instalar nada para usar o sistema.

Variáveis de ambiente:
A senha do banco não fica no código. A conexão (api/conexao.php) lê os
dados pela função getenv(), a partir destas variáveis cadastradas na Vercel:
DB_HOST, DB_PORTA, DB_NOME, DB_USUARIO e DB_SENHA.
